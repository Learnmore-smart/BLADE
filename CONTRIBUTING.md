# Contributing to BLADE

BLADE is an evidence-driven de-hardening pipeline. Contributions that make it
extract more real signal from BLA-hardened artifacts — or flag what can't be
recovered more precisely — are welcome.

## Ground rules

- **No fabricated recovery.** If bytes are information-theoretically destroyed,
  the report must say so (keep+flag, inferred, canonical) — never emit a fake
  "exact" result. Recovery grades are the product's contract.
- **Degrade loudly.** Unknown or shape-drifted BLA variants must be flagged by
  `structuralAnomaly` scoring, not silently passed through.
- **Real fixtures only.** Adversarial tests must be generated by the actual
  `bla-agents` release (see `vendor/bla`, `bla-agents@3.2.4` on npm), not
  hand-written approximations.
- **Preserve legitimate content.** A scrubber that removes one byte of real
  user code is a regression. Ambiguity ⇒ keep + flag.

## Setup

```bash
npm install
node scripts/verify.mjs          # core suite — expect 37 passed, 0 failed
node scripts/verify-all.mjs      # full matrix — 25 suites incl. adversarial
```

The vendored BLA source (used by fixture generators) is gitignored. To
reproduce it:

```bash
npm install --prefix vendor --no-save bla-agents@3.2.4
cp -r vendor/node_modules/bla-agents vendor/bla
```

## Adding support for a new BLA defense

1. Generate a real hardened artifact with the current `bla-agents` release
   (`protectTarget`, `harden`, or the relevant shield API).
2. Add it under `test-fixtures/adversarial/<format>/` with a `run.mjs`-style
   harness or a case in the existing runner.
3. Implement the counter in the owning module:
   - `src/trailer.mjs` — appended trailers, headers, Python source, DEX/EVM/
     JVM/PCAP/UF2/BEAM/plist/native PE-ELF-MachO
   - `src/formats.mjs` — ASAR/WASM/SQLite/safetensors/GGUF
   - `src/js-deharden.mjs` — JavaScript AST passes
   - `src/recovery/` — canonical restoration, name inference, precision
     neutralization, salvage
4. Assert byte-level results where possible (byte-exact restore, or the exact
   kept+flag residue with a reason string).
5. `node scripts/verify.mjs` must stay 37/37 and the affected adversarial
   suites must stay green. New format routes also need an entry in
   `scripts/verify-all.mjs`, a routing expectation in
   `test-fixtures/adversarial/detect/run.mjs` (if corpus-shaped), and a
   `npm run test:<format>` script.

## Style

- Plain ESM `.mjs`, no build step, no TypeScript.
- Node `^22.23.4 || >=24` builtins only; the only deps are `@babel/*` for JS.
- Buffers in, Buffers out. Scrubbers return `{ buffer|code, report }`.
- Comments explain *why* a structure is safe to cut — quote the BLA emission
  shape you're matching.
